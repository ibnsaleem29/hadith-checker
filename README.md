# Hadith Checker [English & Arabic] - Chrome Extension

Search and check Hadith from [Dorar.net](https://dorar.net) and view the
results in Arabic and English side by side.

## Features

- Search Dorar.net by pasting Arabic, English, or part of a Hadith
- Bilingual results — English and Arabic shown side by side
- Automatic translation, with grading, source, and narrator information
- شرح الحديث (commentary) and أصول الحديث (Hadith principles) available inline
- Right-click any selected text on a webpage → **Check in Hadith Checker**
- Open multiple independent searches in separate tabs

## Usage

1. Install the extension.
2. Click the toolbar icon and enter a search, or right-click text you've
   selected on any webpage and choose **Check in Hadith Checker**.
3. Results open in a new tab, in Arabic and English.

English text is an AI-generated translation of Dorar's Arabic content, shown
as an aid to understanding — not a substitute for the Arabic original.
